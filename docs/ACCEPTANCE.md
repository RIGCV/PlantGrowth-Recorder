# 第一版验收范围

实现范围对应已确认的 01—12 项。本地工具模式，不引入账号或云同步。

| 项目          | 验收要点                                                              |
| ------------- | --------------------------------------------------------------------- |
| 01 界面       | 桌面三栏工作台、手机编辑/预览切换；统一字体、颜色和间距               |
| 02 入口       | 新建项目、导入备份、导入 PDF 独立入口                                 |
| 03 预览       | 实际 PDF 页面、缩略图、翻页、缩放、修改自动刷新，过期任务不覆盖新预览 |
| 04 内容编辑   | 封面与记录所有文案、拍摄信息、自定义字段、页眉页脚                    |
| 05 模板       | 三种预设、个人模板、全局/单条范围、模块隐藏和排序                     |
| 06 历史管理   | 多项目、日期排序、补录、同日冲突处理、回收站与归档                    |
| 07 照片与日期 | 普通文件名、手动日期、合法日期、照片多图/图注/排序/旋转/裁剪          |
| 08 追加       | 日期核对、原页面保留、新版项目恢复、导出后继续维护项目                |
| 09 保存       | IndexedDB 事务、自动保存、失败反馈、备份导入、多标签页防覆盖          |
| 10 导出质量   | 中文真实文字、长文续页、图片布局、质量选择、文件命名                  |
| 11 反馈       | 导入/导出/预览进度、错误恢复、防重复提交                              |
| 12 工程       | 核心测试、独立浏览器流程测试、构建、部署/回滚文档                     |

自动化结果以实际测试报告和发布时的记录为准。Chromium 手机尺寸测试不等于真实 iOS 或 Android 文件下载验收；正式扩大用户范围前仍应在目标设备做一次端到端检查。

已知边界：外部 PDF 原始页面不可逐字编辑；未携带项目附件的新 PDF 也视为保留页面导入。原始 PDF 不重新编页码或覆盖封面。字体不覆盖彩色 Emoji 和所有复杂文字排版。静态网站可在线访问，但项目数据仅存于本机，必须依靠备份跨设备迁移。
